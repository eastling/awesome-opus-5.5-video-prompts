What the best prompts have in common

Opus 5.5 doesn't generate video pixels. It writes code (Canvas, SVG, GSAP, Three.js, shaders) that draws every frame, and a headless browser plus ffmpeg turns those frames into an MP4. So the strongest prompts read like a creative brief and an engineering spec at once.

01

Collect assets first

Several of the most-liked prompts open with an "Ask me for:" list (product name, UI states, a royalty-free song) so the model has real material before it writes a frame.

02

Ban the AI tells

Name what you don't want: corner labels, fake UI frames, particle bursts, lens flares, camera shake.

03

Give timing in numbers

Seconds per beat, camera moves of 1.5–3 s, a hook in the first second, the end card held for the last 15%.

04

Make rendering deterministic

"Every frame is a pure function of time" or "one draw(t) function" lets the video render frame by frame without dropped or jittery frames.

05

Sync to sound

Ask for cuts on the beat, or for a soundtrack synthesized in code so timing is exact.

06

Set the bar with a reference

"Like a showreel for a résumé", "like it won an Emmy for main title design", "Apple keynote".
